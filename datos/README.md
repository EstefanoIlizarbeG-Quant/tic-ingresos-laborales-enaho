# Datos locales

Este repositorio utiliza ENAHO 2023–2025 y una validación complementaria con 2022. Los módulos individuales se mantienen fuera del control de versiones. La guía de reproducción describe las entradas por etapa.

Para generar todas las figuras desde las bases preparadas se necesitan `base_mco_complemento_etapa08E.dta` y `base_heckman_estimacion_etapa10.dta`. Puede conservarlas en una carpeta externa e indicarla con `--datos-privados`.

Las tablas agregadas de coeficientes, contrastes y resúmenes se incorporarán en `resultados/tablas/` en el segundo bloque de publicación. Las tablas con datos individuales se conservan en la carpeta privada del proyecto.
