Siete figuras publicadas pueden regenerarse con las tablas agregadas incluidas. Las otras siete requieren las bases locales indicadas en [la guía de reproducción](../docs/reproduccion.md).

El [registro de reconstrucción](python/verificacion_reconstruccion.json) documenta la preparación original de 18 figuras, incluidas las muestras y la conciliación del R² educativo. Catorce se incluyen en esta galería. Las cuatro figuras con valores de observaciones individuales se conservan fuera del repositorio público. El registro no corresponde a una nueva estimación de MCO o Heckman durante la publicación.
